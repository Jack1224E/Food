Using AgentRouter in Codex CLI​

Codex CLI ~/.codex/config.tomlallows you to connect to AgentRouter by configuring a custom provider.

Installation and configuration steps​

1. Install Codex CLI​

bash
# npm 安装
npm install -g @openai/codex

# brew 安装
brew install --cask codex

2. Check the installation results​

bash
codex --version

3. Configure shell global environment variables​

You can obtain the token via https://ps.air-outer.com/console/token :

bash
echo 'export CODEX_GATEWAY_API_KEY="替换为你的AgentRouter API Key"' >> ~/.zshrc
source ~/.zshrc

4. Create a custom provider​

Create ~/.codexa directory, and then create [something] within that directory config.toml.

Field description:

Configuration itemsFill in the information/instructions
modelInitial Default Model
model_providerInitial session uses gateway settings
base_urlhttps://agentrouter.org/v1
For the Claude Opus series, prioritize using Anthropic + Use custom base URL (without specifying the base URL /v1); for other general models, use OpenAI Compatible (with the base URL specified /v1). These two methods should be used in parallel, not mixed.
env_keyObtain your AgentRouter API Key by logging into https://ps.air-outer.com/console/token . Refer to step 3; environment variables have already been set.
nameprovider display name
wire_apiresponses
model_providers.AgentRouter.modelsSupported models are dynamically adjusted and may be added or removed depending on resource availability. Please always refer to the list displayed at https://ps.air-outer.com/console/personal

for the most up-to-date information. The Agent Router currently offers the following models:
OpenAI : gpt-5.6-sol, gpt-6-astra
Anthropic : claude-opus-5, claude-opus-4-8　Supports OpenAI and Anthropic ;
Zhipuglm-5.3 : 　Supports OpenAI and Anthropic;
Deepseek : deepseek-v4-flash　Supports OpenAI and Anthropic.

For endpoint support information for each model, please refer to https://ps.air-outer.com/pricing .

The model name must be exactly the same as on the pricing page (including hyphens). Entering an incorrect or discontinued model will result in a 503 error indicating no available channels.

Parameter example:

toml
model = "gpt-5.6-sol"
model_provider = "AgentRouter"

[model_providers]
  [model_providers.AgentRouter]
    base_url = "https://agentrouter.org/v1"
    env_key = "CODEX_GATEWAY_API_KEY"
    name = "AgentRouter"
    wire_api = "responses"

    [model_providers.AgentRouter.models]
    deepseek-v4-flash = { name = "DeepSeek V4 Flash" }   # name 为模型对外展示名称
    "gpt-5.6-sol" = { name = "GPT-5.6 Sol" }
    "glm-5.3" = { name = "GLM-5.3" }

5. Testing and Verification​

bash
codex   # 启动 codex

codex --config model='"glm-5.3"'   # 启动 codex 时指定模型

IMPORTANT

The Codex CLI /modelcommands only display OpenAI's official models (visible after logging into your ChatGPT account), and will not display models from custom third-party providers. You need to use the command codex --config model=...to switch the configured model.
